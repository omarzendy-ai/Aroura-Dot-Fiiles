MacShell & Custom Hyprland Shells 🍎🌌
A collection of custom desktop shells built with QuickShell for Hyprland on Arch Linux. This repository includes 3 distinct shells merged into one launcher, ranging from ultra-lightweight performance setups to original custom-built designs.

(Note: The base MacShell was originally created by another developer, while I completely modified it and built the other two shells from scratch.)

🎨 Included Themes & Shells (In Order)
1. MacShell Classic (Ultra-Lightweight & Fast)
Overview: A heavily stripped-down and optimized classic macOS-style shell designed for maximum speed and minimal resource usage.

Liquid Glass & Performance: Features a lightweight, bug-free Liquid Glass effect. Tested directly on older hardware like Intel HD 4600—runs smoothly with zero issues.

Built-in Features: Includes Spotlight search, Clipboard manager, and a Wallpaper Changer, all powered by and integrated into QuickShell scripts.

Troubleshooting: If you run into any minor bugs or path issues, please try to troubleshoot and fix them on your own first.

2. Omar-Shell (Custom Design from Scratch)
Overview: An original theme built entirely from scratch based on my own vision and design philosophy.

Visuals & Performance: Slightly heavier than MacShell Classic, featuring a clean aesthetic, subtle blur, and a heavy Liquid Glass look.

Features: Minimalist feature set focused on looks, highlighted by a smooth App Launcher that pops up from the bottom with sleek, simple animations.

3. Aroura-Shell (Full Custom Experience)
Overview: A complete, standalone shell built 100% by me without any external templates—a bit eccentric and unique (yes, I'm a weirdo, appreciate the hard work! 😄).

Features & Aesthetics:

Custom Control Center

Built-in Wallpaper Changer & Clipboard manager

Integrated App Launcher

Signature visual touches including a custom glowing logo designed from scratch.

Hardware Compatibility: Relatively lightweight and runs very smoothly on both modern and older integrated GPUs (such as Intel HD 4600 and Intel UHD 620).

🚀 Unified Launcher & Installation
All 3 interfaces have been merged together into a single unified launcher for easy switching.

Installation Script: There is an install.sh / setup.sh script included in the repository. I haven't fully verified if it works out-of-the-box on every setup—if you fix or improve the install script, please submit it in the GitHub Issues! I'll reach out, share my Discord with you, and thank you personally for fixing it.
